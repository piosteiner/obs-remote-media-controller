Privacy

Last updated 17 October 2026

In short

No cookies, no analytics, no advertising, no tracking. This is a personal tool for controlling what OBS Studio shows during a stream or game session. The control pages need an admin key; without it you only see the key form.

Who is responsible

Pio Gino Steiner, Switzerland · info@piogino.ch
The OBS Media Controller is a private, non-commercial hobby project.

What happens when you visit

WhatProvider and locationWhat it receives
The website itself GitHub Pages: GitHub, Inc., USA (privacy statement) Your IP address, the page requested, browser details. GitHub logs these for operation and security.
Scenes, images and the live connection Our own server api.piogino.ch at Infomaniak, Switzerland Your IP address, time, the request, browser details, written to a server log for operation and security. The log is deleted after 14 days; it is not analysed or passed on.

The player runs in YouTube's privacy-enhanced mode (youtube-nocookie.com); YouTube may still store data in your browser once a video plays.

Content you add

Images uploaded to the library and the scene setup are stored on our server in Switzerland, so they can be shown in OBS. Only holders of the admin key can add or delete them.

Stored in your browser

This site sets no cookies. It keeps two values in your browser's local storage:

  • obs-admin-key: the admin key, once you have entered it, so you don't have to type it again
  • obs-player-collapsed: whether the player panel is folded away

The key is sent to our server with each control request to authorise it; the other value never leaves your device. You can delete both by clearing the site data in your browser's settings.

Data abroad

GitHub and Google are based in the USA, so your IP address and the request reach the USA when their services are used. Both state that they participate in the Swiss-U.S. Data Privacy Framework; for details see the privacy statements linked above. Our own server is in Switzerland.

Your rights

Under the Swiss Federal Act on Data Protection (FADP) you can ask what personal data about you is processed, and have it corrected or deleted. Write to info@piogino.ch. You can also contact the Federal Data Protection and Information Commissioner (FDPIC).

Changes
